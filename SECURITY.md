# Security policy

Reel Meter runs on YouTube, Instagram, TikTok and Facebook pages and is built so that no data leaves the device.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private
**Security > Report a vulnerability** form on this repository instead.

Useful reports include a way around a block or limit that a normal user could not already do by disabling the
extension, any path that would send data off the device, or any way a web page can read or change the extension's data.

## Known limits (not treated as vulnerabilities)

Turning the extension off, DevTools, moving the system clock forward, reels inside iframes, and some page types
the extension does not classify (Instagram `/p/` posts, Facebook `/watch`, TikTok `/explore`). See `README.md`.
